# zichuanxu/homebrew-tap

Homebrew packages for [godl](https://github.com/zichuanxu/godl), a fast, cross-platform download manager.

```bash
brew install --cask zichuanxu/tap/godl-desktop   # macOS app
brew install zichuanxu/tap/godl                  # CLI and service (macOS, Linux)
```

godl is unsigned; see the [install guide](https://github.com/zichuanxu/godl/blob/main/docs/install.md) for the one-time Gatekeeper step. The formula and cask are generated by godl's release workflow.

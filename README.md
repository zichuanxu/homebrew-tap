# zichuanxu/homebrew-tap

Homebrew packages for [NimGet](https://github.com/zichuanxu/nimget), a fast, cross-platform download manager.

```bash
brew install --cask zichuanxu/tap/nimget-desktop   # macOS app
brew install zichuanxu/tap/nimget                  # CLI and service (macOS, Linux)
```

NimGet is unsigned; see the [install guide](https://github.com/zichuanxu/nimget/blob/main/docs/install.md) for the one-time Gatekeeper step. The formula and cask are generated by NimGet's release workflow.
